# Cidade Dorme

Jogo de dedução social (assassinos × cidade) para celular.

- **Online:** crie uma sala e passe o código; cada jogador usa o próprio celular. Tem chat e voz.
- **Sozinho:** jogue contra agentes de IA (com chave gratuita do Gemini eles conversam de verdade).
- **Um celular só:** passe o aparelho de mão em mão.

Sem servidor próprio: o celular do anfitrião comanda a partida e os outros se conectam a ele (PeerJS/WebRTC).
